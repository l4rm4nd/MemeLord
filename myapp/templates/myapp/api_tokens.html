Usage

Fetch your memes (replace TOKEN):

curl -H "Authorization: Bearer TOKEN" \
     {{ request.scheme }}://{{ request.get_host }}/api/memes/

# Get a single random meme (same filters apply):
curl -H "Authorization: Bearer TOKEN" \
     {{ request.scheme }}://{{ request.get_host }}/api/memes/random/

Available query parameters:

Parameter Description Example
usernameFilter by uploader username (exact)?username=alice
titlePartial title search?title=cat
tagFilter by tag slug; repeat for AND logic?tag=funny&tag=cats
date_fromUploaded on or after (YYYY-MM-DD)?date_from=2024-01-01
date_toUploaded on or before (YYYY-MM-DD)?date_to=2024-12-31
media_typeimage or video?media_type=image
ordering-upload_date (default), upload_date, title, -title?ordering=title
pagePage number (default 1)?page=2
page_sizeItems per page, 1–100 (default 20)?page_size=50
